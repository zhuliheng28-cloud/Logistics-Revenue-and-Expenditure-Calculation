# 物流收支流水自动化计算与拆分处理工具 (Logistics Revenue & Expenditure Calculation)

专为跨境电商与跨境物流账单收支流水设计的自动化清洗、汇总与比例拆分计算工具。解决人工核对运费繁琐、超长订单号失真、多包裹复合订单费用分摊难等核心痛点。

---

## 核心业务逻辑与特性

1. **文本安全读取 (`dtype=str`)**
   - 强制使用全字符串模式读取 Excel 数据源，避免 16 位以上长订单号在解析时发生精度截断或自动转为科学计数法。

2. **金额清洗与符号保留**
   - 基于正则自动化剔除 `CN￥`、`CNY`、逗号等干扰字符，精准提取数值并保留真实的收支正负符号。

3. **主费用有效性校验**
   - 严格以“正向配送费”作为有效订单准入标志，自动过滤剔除缺少主运费的无效杂项账单。

4. **大额复合订单按比例拆分 (Split Logic)**
   - **触发条件**：订单内包含多次“正向配送费”且订单总变动金额绝对值 `> 180`。
   - **拆分规则**：将母订单拆分为原订单号与 `_1`, `_2`, ... 等子订单。
   - **费用分摊**：其余附加杂费（如挂号费、处理费等）依据各项主配送费金额占总主费用的权重比例进行精准分摊，并做平账校验。

5. **透明计算明细与原表保留**
   - 新增“金额计算明细”列，完整记录各项费用的加总与比例分配算法逻辑。
   - 结果文件在 `Sheet1` 保留原始输入全量数据，`Sheet2` 写入清洗汇总后的最终成果，确保数据可回溯。

│   ├── analyze_items.py                  # 费用项与正负符号探查脚本
│   ├── batch_and_zip.py                  # 批量处理与压缩工具

pip3 install -r requirements.txt

## 使用方法

### 方式一：macOS 一键拖拽执行（推荐）
1. 双击运行根目录下的 `一键处理收支流水.command`。
2. 按照终端提示，将待处理的 Excel 文件直接拖入终端窗口并回车。
3. 程序将自动在原文件同目录下生成 `[原文件名]_processed.xlsx`。

### 方式二：命令行调用
```bash
python3 income-expense-processor/scripts/process_excel.py <输入文件.xlsx> <输出文件.xlsx>
```
